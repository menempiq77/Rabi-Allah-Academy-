# Rabi Allah Islamic Academy

A modern, professional website for **Rabi Allah Islamic Academy** rebuilt from the original WordPress site at `rabiallahdotcom.wordpress.com`.

## About

This project preserves the same information and mission of the original website while presenting it in a cleaner, more professional, and mobile-friendly design.

**Tagline:** From Learning to Living Islam

## Pages

- **Home** — Hero with background image, welcome, course preview cards with images, how-it-works steps, features, and student testimonials
- **About** — Vision, mission, the Rabi Allah way, why choose us, founder, and well-qualified teachers
- **Courses** — Course cards with images plus a full private-class pricing table (30, 45, and 60 minute sessions)
- **Course Detail** — Hero image, course info, what you will learn, and detailed pricing table
- **Articles** — Article card grid (image + title) linking to individual article pages
- **Article Detail** — Full SEO-rich article content
- **Contact** — Email, location, hours, social links, and contact form

## Courses

Courses mirror Blessings Academy and include Arabic through Qur’an:

Quran Reading Basics, Quran Recitation, Tajweed Rules, Quran Memorization, Arabic Language, Arabic through Qur’an, Islamic Studies, Tafsir, Sirah, Hadith, Aqidah, and Islam for New Muslims.

Only **Islam for New Muslims** is free; all other courses use the private-class pricing below.

## Pricing

Private one-to-one online class fees are based on Blessings Academy structure:

- **30 minutes:** from $20 to $85 / month
- **45 minutes:** from $27 to $120 / month
- **1 hour:** from $36 to $160 / month

## SEO Features

- Unique title tags and meta descriptions on every page
- Keyword-rich headings and content
- Canonical URLs and Open Graph / Twitter card meta tags
- `robots.txt` and `sitemap.xml`
- Schema.org structured data (EducationalOrganization, Course, Blog, ContactPage)
- Semantic HTML and fast-loading static build

## Tech Stack

- [Vite](https://vitejs.dev/)
- [React](https://react.dev/)
- [React Router](https://reactrouter.com/)
- [Tailwind CSS](https://tailwindcss.com/)
- [Lucide React](https://lucide.dev/) icons

## Getting Started

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

The production-ready files will be in the `dist/` folder.
